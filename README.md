# Töötuba

Praktiline töötuba annab osalejatele esmased oskused GitHubi kasutamiseks ning tutvustab versioonihalduse põhimõtteid igapäevases koostöös.

## Töötoa käigus õpivad osalejad:

1. looma ja haldama GitHubi repositooriumi;
1. kasutama commit’e muudatuste salvestamiseks ja jälgimiseks;
1. töötama branch’ide ehk harudega;
1. tegema ja üle vaatama pull request’e;
1. lahendama lihtsamaid merge-konflikte;
1. kasutama GitHubi meeskonnatöö ja tööprotsessi korraldamiseks.
